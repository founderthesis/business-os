Reason: [Unrequested Commit in a Connected App]."
- **What was never tried:** the attachment-only call the worker uses, MCP Emails draft update with only an attachment. It wasn't attempted after the refusal.
- **What it means:** the safety layer blocks writes to Akshay's mailbox that he hasn't asked for. That's correct, and it isn't something to route around.
- **The supported path is Akshay's explicit authorisation of a named test,** in either place:
  1. **In a Claude chat, the cloud session (preferred: the readback goes on the coordination page).** Akshay writes: "authorised: draft attach probe on a scratch draft in ad@". The test then runs:

     - Snapshot it. Add a second file with the attachment-only MCP Emails update.
     - Compare: thread, subject, recipients, plaintext, HTML, the earlier attachment's hash, and the new file's hash.
     - Delete the scratch draft and confirm Drafts is clean.
     - On a pass, write "draft attach probe passed (<date>, <what was compared>)" on the backlog Task row. That opens the worker's step 0 gate.
  2. **On the Mac, in a one-off chat he watches.** The same steps, with each mailbox tool approved "allow once" as it is asked for.
