## Dry run (10 Nov, read only, Gmail connector and Bash only)

- get_thread in PLAIN_TEXT view lists each message's attachments (filename, id, mimeType). METADATA_ONLY and MINIMAL don't.
- download_gmail_attachment saves the bytes to a file and prints the path; nothing is retyped. Stated cap 12 MB.
- A real PDF pitch (QubeHealth profile, 54 KB): pypdf gave 4,426 characters, pdftotext 3,459.
- A real .docx pitch (Communicate India bio, 2.4 MB): python-docx gave 2,288 characters.
- Built locally: password PDFs fail cleanly; image-only PDFs give about 1 character (no OCR in the container); old .doc fails in python-docx; .pptx works with python-pptx.
- Check before deploy: the Evals session's machine has pypdf, python-docx and python-pptx.
