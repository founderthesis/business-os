## Rev 2 (20 Oct): Codex's 08:03 review, decisions 346 and 347

### What changed from rev 1

1. **Snoozes (Zoya SNOOZED ASKS).**
   - A snoozed segment is found anywhere in Next action, not only at the start.
   - Each snoozed segment returns on its own date, whatever Next date or another segment says.
   - On return only that segment is rewritten. Its held steps lose the "(held for Akshay's snooze)" mark, and every other segment and owner stays.
   - Next date becomes the earliest date still open on the row.
   - A retry finds nothing left to do.
   - The Controls page snooze section now matches.
2. **Prior appearance (Controls page section 2, Zoya STEP 0e).**
   - Each appearance is recorded exactly: show, date and episode.
   - Repeat wording is used only for a completed recording on this row's own Show, naming that show and month.
   - An appearance on another show only is context for Akshay, never a claim.
   - A name match alone is not an appearance.
3. **Run report.**
   - The rev 1 paragraph (with its invalid Source Agent and no invocation key) is gone.
   - Zoya gets the cleanup-accepted AR-20261018-8 RUN RECORD text, byte-identical to the patch: Source empty, Kind Note, Source ID "run:zoya:<run id>", where the run id is the provider session id or a one-time synthetic token.
   - Start and final state go on one record, and a retry reuses it.
   - The report body opens with: due, sent, held (by rule), blocked, remaining.
   - The inbox's AR-8 hunk is not in this package; the inbox has no headroom until the trim lands.
4. **Seven-day clock (decision 346).**
   - Zoya LIMITS and ONE PERSON, ONE ASK count only substantive mails.
   - An administrative loop-in or an incidental Cc never starts or resets the clock.
   - A mail with a real ask counts even if it also loops someone in.
   - Every other limit is unchanged.
5. **WhatsApp blurb loop retired (decision 347).**
   - Removed from the WhatsApp prompt:
     - the founder-thesis-blurb tool line;
     - the "a blurb goes as its own message" line;
     - the posted-blurb dedupe key;
     - 0b (new blurb posts and WhatsApp-triggered rewrites), now one retired line;
     - "blurbs posted or edited" in the report.
   - 0a e (a message about a blurb) now writes Akshay's words under the guest's newest Blurb section and replies once with that recording's editing-chat link, or says the chat isn't set up yet.
   - Unchanged: intake, coordination, digests, team asks, STEP 3d and the FT Community work.
   - Unchanged in calendar: STEP 4b and 4b2 still draft the first sourced blurb.
