Parent page: https://app.notion.com/p/3fb19a301a7f812e9e4ddc69de65c590 (the "Decisions" page under Business OS developer; create the database inside it)

## What to do

1. Inside the page above ("Business OS developer"), create a full-page database named **Decisions**.
2. Give it exactly these properties:
   - **No.** (number). Default sort: No. descending.
   - **Decision** (title): the short name from the table.
   - **What we decided** (text)
   - **Why** (text)
   - **Date** (date). Leave empty where the table cell is empty.
   - **Area** (select) with exactly these options (option names contain no commas): Data model, People and dedupe, Inbox, Evals, Zoya and follow-ups, Calendar and recordings, Sponsored and revenue, Mail wording and voice, Links, WhatsApp and community, Host shows (un# / B2S / HBD), Team and roles, Platform and tooling, Release and episodes.
   - **Routines** (multi-select) with exactly these options: Inbox, Evals, Zoya, Calendar, WhatsApp, Daily sweep, Dossiers, Salesblink, Community sync, Mac tasks, None. Cells hold one or more values separated by commas.
   - **Status** (select): In force, Superseded, Open.
   - **Replaced by** (text): the decision numbers, or the override, that replaced a superseded row.
   - **Who** (select): Akshay, Claude (proposed and agreed).
3. Create one row for every row of the table below, copying each cell as written into the property with the same name. Do not reword anything.
   - The source log numbers two different decisions as 104. Create both rows with No. = 104; they have different names.
   - Rows O1 to O3 are open questions. Leave No. empty for them and put the O-number at the start of the Decision title (for example "O1: Field-level spec").
4. Create these views on the database:
   - **In force**: table, filter Status = In force, sort No. descending, no grouping.
   - **By area**: board grouped by Area, filter Status = In force, sort No. descending.
   - **Superseded**: table, filter Status = Superseded, sort No. descending.
   - **Open**: table, filter Status = Open.
5. Do not group any table view into sub-tables. One table per page; sort instead.
6. Do not change any other page or database.
