# Tags

Substack turns every tag into an indexable hub page at
`founderthesis.com/t/<slug>` — a browsable playlist by theme AND an SEO hub that
every tagged article links into, concentrating link equity. So tags do double
duty: reader segmentation and search.

**The rule:** a small, controlled taxonomy, assigned consistently. 50 tags = no
tags. Assign **1–3 tags per article, chosen only from this fixed list** — never
invent a new one. Most episodes are a single sector; add a second only when the
company is genuinely cross-sector (a fintech-for-farmers gets Fintech +
ClimateTech).

## The taxonomy (10)

| Tag | Covers |
| --- | --- |
| **Fintech** | lending, payments, credit, neobank, insurtech, wealth |
| **D2C** | consumer brands, beauty, grooming, FMCG, apparel, food |
| **SaaS** | B2B software, enterprise, dev tools, IT services, services-to-product |
| **Deeptech** | robotics, drones, space, semiconductors, AI infrastructure |
| **Healthtech** | hospitals, diagnostics, pharma, digital health |
| **Edtech** | upskilling, schools, test-prep, education finance |
| **Consumer Internet** | marketplaces, social, gaming, content, community |
| **Mobility & EV** | logistics, auto, electric vehicles, fleet |
| **ClimateTech** | energy, sustainability, agritech, cleantech |
| **VC & Investing** | funds, angels, investors, private credit |

If a company truly doesn't fit, pick the closest sector rather than inventing a
tag — keeping the hubs dense is more valuable than perfect precision.
