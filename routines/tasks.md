# Task types

Tasks are created automatically from Episode status and tags. Change this table, not Notion, to change who gets what.

Owners for now: copy goes to Ranjita; every video and production task goes to Sarika, who runs Francis, Vinayak and Ajab and will split work from her own dashboard.

## Order of work

Client episodes first, then Tier 1, then Tier 2, then Tier 3 Spotlight. Due dates for lower tiers move when a client episode lands, and the release calendar shows the knock-on.

## Tier 1 (full pack)

| When | Task | Owner | Due | Closes when |
|---|---|---|---|---|
| Transcript in | Pick theme and final copy | Ranjita | Planned release minus 7 days | Every copy section in the working doc has a tick |
| Transcript in | Edit episode (cut list and lower thirds linked) | Sarika | Planned release minus 5 days | Marked done |
| Copy done | Thumbnail design | Sarika | Planned release minus 3 days | Marked done |
| Edit done | Shorts and reels | Sarika | Planned release minus 2 days | Marked done |
| Tag "Guest review" | Send rendered frame to guest for accuracy check | Sarika | Planned release minus 3 days | Guest approves |
| Ready | Release emails and posts | Ranjita | Release day | Release emails sent |
| Release day | Send reels to guest and company for their Instagram | Sarika | Release day | Reels email sent |

## Tier 2 and Tier 3 Spotlight (light pack)

Stage A runs titles and show notes only; no host intro, soundbite bank or Substack draft unless asked.

| When | Task | Owner | Due |
|---|---|---|---|
| Transcript in | Pick title and show notes | Ranjita | Planned release minus 4 days |
| Transcript in | Edit episode | Sarika | Planned release minus 3 days |
| Release day | Send reels to guest | Sarika | Release day |

## Defaults

- If Planned release is empty, due dates count forward from the trigger: copy +5 days, edit +7 days.
- Human by Design episodes get the "Guest review" tag by default (science and PhD guests check accuracy before release).
