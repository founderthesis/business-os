# Task types

Tasks are created automatically from Episode status. Change this table, not Notion, to change who gets what.

| When | Task | Owner | Due | Closes when |
|---|---|---|---|---|
| Transcript in | Pick theme and final copy | Ranjita | Planned release minus 7 days | Every copy section in the working doc has a tick |
| Transcript in | Edit episode (cut list and lower thirds linked) | Sarika | Planned release minus 5 days | Marked done |
| Edit done | Shorts | Sarika | Planned release minus 2 days | Marked done |
| Copy done | Thumbnail design | Sarika | Planned release minus 3 days | Marked done |
| Ready | Release emails and posts | Ranjita | Release day | Release emails sent |

If Planned release is empty, due dates count forward from the trigger: copy +5 days, edit +7 days.
