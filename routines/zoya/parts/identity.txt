MESSAGE IDENTITY (Codex, 22 Oct). A mail's identity is its RFC Message-ID header, the same in both mailboxes. Wherever this prompt sets an Activity's Source ID to a message id, use "msgid:<Message-ID without angle brackets>" (the provider's own id only when the header can't be read). Before creating a mail Activity, look up that key and the provider ids you hold for the message (Gmail id, MCP Emails id): any hit means it is logged, so add only a missing link.
