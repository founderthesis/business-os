MESSAGE IDENTITY. A mail's identity is its RFC Message-ID header, the same in both mailboxes. MCP Emails email_read shows In-Reply-To and References but not the message's own Message-ID: read it with action original (decode it in Bash, keep only that line) or by Gmail search rfc822msgid. Wherever this prompt sets an Activity's Source ID to a message id, use "msgid:<Message-ID without angle brackets>" (the provider's own id only when the header can't be read). Before creating a mail Activity, look up that key and the provider ids you hold for the message (Gmail id, MCP Emails id): any hit means it is logged, so add only a missing link. Two Sent copies with one Message-ID are one send (the provider files its own copy). Every Email out Activity carries the sent plain-text body in its page body.
