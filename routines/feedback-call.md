# Weekly release feedback call

Input: the Gemini notes for the "FT Release Feedback Call" (weekly, ~10 invitees).

After each call:
1. Split the notes by episode discussed.
2. For each episode, log an Activity (Kind: Meeting, Source: Gemini notes) and add the qualitative verdicts to the episode's Team feedback (e.g. "intro relies too much on AI", "VO praised").
3. Record the numbers reviewed on the call (views, watch duration, traffic sources, new viewer share) on the episode.
4. Feed verdicts on intros, titles and thumbnails into the matching skill's learning record.
5. Turn named action items into Tasks with the named owner, or Queue items for Akshay.

The release-frequency test agreed on 1 Oct 2026 is reviewed after one month (around 1 Nov) using these numbers.
